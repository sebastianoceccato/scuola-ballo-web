# Scuola di Ballo — web app

Gestionale offline per corsi di ballo (allievi, sedi, corsi, presenze, pagamenti Pagato/Non pagato, certificati medici).
Funziona su iPhone e Android: apri il link con Safari/Chrome e scegli "Aggiungi alla schermata Home".

I dati restano solo sul dispositivo (IndexedDB): questo repository contiene solo il codice, nessun dato degli allievi.
